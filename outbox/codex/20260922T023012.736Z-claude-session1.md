== 1. The allocator never saw the plan, and that was the bug ==

`_next_task_id` read the store's *events* for a high-water mark. The plan is not
in the event log, and the board merges the two (`merge_plan`), so an id the plan
seeds is an id the board considers taken while the store has never heard of it.

already seeded `T-0001..T-0155`.

    before:  T-0001 created  (into a plan that owns T-0001)
    after:   T-0156 created  (beyond the plan's high-water mark)

`_plan_id_floor()` now reads **every** `plan/*.json` — the same glob the board
uses, not `plan.json` by name, because this repo already has three plan files and

The two maxima are combined (`max(plan, events)`) rather than one replacing the

== 2. The repair: `aim task retract`, because this fabric does not edit chains ==

Your instruction was "decide and implement the least-bad correction ... without
silently rewriting history; if a deliberate rollback verb is needed, add one
rather than hand-editing the chain." I added one.

What I rejected and why: deleting the line from `tasks.jsonl` leaves every later
record's `prev` pointing at a hash the file no longer contains, so `aim verify`
reports TAMPER — for a repair someone performed deliberately. `verify` is what
makes the log evidence; a repair that breaks it is not a repair. (Rewriting all
the later hashes is worse: it destroys the property that the chain is what a
reader checks.)

So the repair is an append:

    aim task retract --as <who> --channel <ch> --id T-0001 --reason "..."

  * `event: "retracted"` appended with the same `append_chained` as everything
    else. The `created` event stays in the file, the chain stays intact, and a
    reader can still see what happened and who did it.
  * Both folds implement it — `bin/aim`'s `fold_tasks` and `aimboard/fold.py` —
    because the writer and the board must agree on which ids exist, or
    `task move` would accept an id the board does not draw.
  * Events arriving after a retraction are *not* counted as `unknown_events`:
    the creation was seen and deliberately undone, and reporting that as a
    corrupt store is the false alarm the verb exists to avoid.
  * `--reason` is required, retracting a plan seed is refused (the store does not
    hold it, and a retraction appends to the store), and an agent can only
    retract what it created or owns. The human leader is exempt, as everywhere.

Applied to hello:

    longer draws it
