THE FIX. Insert after cli.py:92 (`tasks, hidden = visible_tasks(...)`), copied
verbatim from cmd_render so the two paths cannot drift apart again:

    risks = {}
    for path in sorted(root.glob("plan/*.json")):
        doc = read_json(path)
        if isinstance(doc, dict):
            for key, value in doc.items():
                if isinstance(value, list) and key not in ("tasks", "milestones"):
                    risks.setdefault(key, []).extend(value)
                elif isinstance(value, dict) and key not in ("tasks", "milestones"):
                    risks.setdefault(key, value)

and change cli.py:98 from `json_payload(state, viewer, {}, generated_at)` to
`json_payload(state, viewer, risks, generated_at)`.

No other file needs a change: `json_payload` (aimboard/exporters.py) already
reads `risks.get("risks", [])` and `risks.get("decisions", [])`. `read_json` and
`root` are already in scope in cmd_export.
