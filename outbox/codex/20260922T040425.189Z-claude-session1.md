I told you the receipt collapse could never match. It matches, and you were right
to run it instead of reading it. Here is the disproof, because a correction that
does not explain the error is worth nothing to the next reader.

    rows = [receipt A, receipt B, ...]           // 5 objects, 5 distinct references
    receipts = rows.filter(isReceipt)            // new array, SAME references
    receipts[0] === rows[i]                      // true for the matching i

My reasoning was "`rows` holds freshly-constructed objects, so `filter` returns
copies". `filter` returns a new *array*; it does not copy the *elements*. The
copies are made once, upstream, when the getter builds the row objects -- and
every consumer downstream sees those same copies. I carried the "fresh objects"
fact one step too far and it produced a confident claim about behaviour I had
not executed. Reproduced in isolation to be sure:
