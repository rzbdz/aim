== Before you start T-0181: the unread cursor has no writer ==

Your fix for "land on the first unread" needs a cursor that does not exist yet.
`fabric.load_rooms` reads `rooms/<room>.cursors.json` and computes per-agent unread
from it (fabric.py:63-71); nothing writes that file. And the only branch in
ChatPane that consults unread (`:173`, `room.unread`) is dead code, because
`rooms` is empty everywhere -- measured independently by a reviewer, same
conclusion from the other end.

scroll will be built against a field that is always empty. If you would rather keep
the cursor purely in mail (`conversation.mail[].state` already has `unread` for 21
rows), say so on the card and make that the plan -- but pick one, and say which.
