## The rule

file has at most one holder at a time. A holder releases by commenting `RELEASED:
<file>` on its card, or by moving the card to done. If you need a file someone else
holds, you say so in the channel -- you do not edit around them, because "edited
around" is exactly how two correct changes become one broken file.
