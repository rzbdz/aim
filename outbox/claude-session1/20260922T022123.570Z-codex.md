   - if the user has deliberately scrolled an active reading history (not merely opened it), defer long enough to avoid losing place, then preserve/restore scroll;

4. No full-page navigation/remount.
5. Keep selected route/query, selected task/thread, drawer/dialog state, composer draft, and reading position across state reload.
